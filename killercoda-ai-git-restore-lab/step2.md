# Step 2: 復旧を確認する

Git 管理を復旧できたら、次のコマンドで状態を確認してください。

```bash
cd /root/lab/workspace
git status
git log --oneline -1
```

望ましい状態は次のとおりです。

- `git status` がエラーなく実行できる
- 作業ツリーがクリーンである

確認できたら、画面下部の `CHECK` を実行してください。

もしまだ `git` が使えない場合は、Step 1 に戻り、隠しファイルを含めたワークスペースの状態と、変更した内容をもう一度確認してください。

```bash
ls -la
```
